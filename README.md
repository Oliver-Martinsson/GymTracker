Gym Tracker 🏋️
Gym Tracker is a web application for logging strength training workouts and tracking progression over time.

Users log their workouts with exercises, sets, reps and weight. Based on this data, the app calculates personal records, estimated one-rep max (1RM) and weekly training volume, and suggests weights for the next workout according to a selected training program.

The project is built in C# with Blazor Server, Entity Framework Core and SQLite, with a strong focus on testable architecture, SOLID principles and unit testing. Development follows a DevOps workflow with feature branches, pull requests and GitHub Actions pipelines that build and test the code automatically.
